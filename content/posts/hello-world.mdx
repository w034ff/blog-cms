## はじめまして

このブログでは、日々の技術学習や開発の記録を書いていきます。
Next.js App Router と MDX、Tailwind CSS で構築しています。

## できること

- Markdown で記事を書く
- コードブロックは自動でハイライト
- タグとカテゴリで分類

## コード例

TypeScript のサンプル:

```ts
type Greeting = {
  name: string;
  message: string;
};

function greet(g: Greeting): string {
  return `${g.message}, ${g.name}!`;
}

console.log(greet({ name: "World", message: "Hello" }));
```

シェルコマンドも:

```bash
npm run dev
```
